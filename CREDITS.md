## Format

The skin folder layout (a `Body/` folder of PNGs named after the game's sprites, 8 pixels per unit) is the layout used by the skin portal and by the ChangeSkin mod by 05126619z. No code from that mod is used.

## Character

Avali are a fan species from Starbound community lore. The values in `characters/avali_avary.json` are this pack's own balance.
